# Agents

This project is **Contexere** (formerly OMNI). Read [CONTRIBUTING.md](CONTRIBUTING.md)
before changing anything; it holds the standards, the gates and the workflow. Follow
its "Working with an AI agent" steps: start from an issue, read the project's
direction, stay inside the issue, prove the change, and read the review before merging.

Write Contexere, and `contexere` for the command, in everything a person reads. Keep the
old names that something parses (`[OMNI` markers, `OMNI_*` variables, `~/.omni`, the
`omni` command): the full list is in CONTRIBUTING.md under "Naming: Contexere, not OMNI".
