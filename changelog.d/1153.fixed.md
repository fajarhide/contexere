- **A shell inside a double-quoted `$(...)` could read a credential source unrefused (#1153)**: on main after #1152, `echo "$( bash -c 'cat .env')"` was allowed by the pre-hook and not withheld by the post-hook, because the quote tracker that finds the shell before a `-c` kept the outer double quote open inside `$(` and read `bash` as text. The tracker now remembers the quote a `$(` left and restores it at `)`. A shell before a `-c` also has to sit where a command starts (after wrappers, a container's `exec`, `find -exec`, `--`, or a `$(` or backtick), so `printf '%s\n' bash -c ...`, which only prints the name, is no longer refused. The check is a single pass, with no recursion.
