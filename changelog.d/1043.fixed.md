- **The names a credential grants are delivered (#1043)**: a Vault role printed `token_policies = ["github-ci-prod", "default"]` as `token_policies = [REDACTED]`, because the key matched the strong `TOKEN` pattern and the list-of-names rule from #974 only applied to a bare `KEY`. A key with a `policy`, `scope` or `role` segment now passes when its value is a plain lowercase name or a list of them. A value with mixed case, a colon or a known key prefix stays hidden.
