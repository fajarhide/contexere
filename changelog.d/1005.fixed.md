- **Session state is kept, and each agent keeps its own (#1005)**: the session tracker wrote on a thread nothing waited for, so the hook process exited first and 12 calls left 2 rows. It now writes before the hook returns. Hooks and the MCP server also loaded the newest session of any project, so with several agents one could read and overwrite another's; they now load the session this agent last used in this project, or start a new one. The pipe and `exec` still load the newest session, since they record no agent identity yet.
