- **A binary path with a space no longer disables every hook (#1002)**: hooks were written as `/dir sp/contexere --pre-hook`, so the host's shell ran `/dir`, got exit 127, and Claude Code carried on with no hook at all, the credential guard included. Claude Code, Codex, Cursor and Gemini now quote the path when it needs it; a test runs the written command through `sh` from a directory named `dir sp $x` and gets the binary. A plain path is written exactly as before. Codex's `config.toml` also escapes the path, where a raw `C:\Users` read `\U` as an escape.
