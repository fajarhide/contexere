- **The OpenClaw and Pi plugins call `contexere` (#1189)**: both fell back to the `omni` command when no path was set, and `contexere init --openclaw` never sets one, so on 0.9.0, which installs no `omni`, they would have failed to start the binary and, failing open, stopped distilling with nothing on screen to say why. They now default to `contexere`, OpenClaw declares it as its required binary, and a path already set in `omniPath` still works.
