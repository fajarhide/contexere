- **A count under a database URL key was hidden (#1144)**: `DATABASE_URL=1`, the output of `grep -c "^DATABASE_URL=" .env` printed per name, came back as `[REDACTED]` while `POSTGRES_URL=1` passed, because `DATABASE_URL`, `REDIS_URL` and `MONGO_URL` are named credential keys and a bare number was judged like any other value under them. Checking which names an env file defines without printing a value is the safe way to inspect it, and two of five counts were unreadable. A bare number (or `3/10`) under any `*_URL` key is now delivered. A number under a holding key (`DB_PASSWORD=123456`) and a URL carrying a password stay hidden.
