- **`contexere carry list` shows what a new machine would need (#1092)**: one row per MCP server each installed agent has configured (Claude Code, Codex, Cursor, Gemini, Cline and the JSON-config hosts), with the transport, the command or URL, and the names of the env vars and headers it uses. Values never appear: a URL loses its query, its userinfo and any token-shaped path segment. A config that does not parse prints an error row. `--json` prints the same rows, and Contexere's own server is left out.
