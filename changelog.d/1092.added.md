- **`contexere carry list` shows what a new machine would need (#1092)**: one row per MCP server each installed agent has configured (Claude Code, Codex, Cursor, Gemini, Cline and the JSON-config hosts), with the transport, the command or URL, and the names of the env vars and headers it uses. Values never appear: a URL loses its query, its userinfo and any path segment of 16 bytes or more, whatever its characters. Codex's `env_http_headers` lists the env var behind each header. On a fixture `HOME` with a token placed in an env value, a header, an argument and a URL, neither the text nor the `--json` output carried it. A config that does not parse prints an error row. `--json` prints the same rows, and Contexere's own server is left out.
