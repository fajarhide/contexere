- **The Claude Code skill reads both marker prefixes and speaks Contexere (#1064)**: the binary still prints `[OMNI` in this release and switches to `[CONTEXERE` in 0.9.0, so the published skill and the markers page now tell an agent to treat `[CONTEXERE: ...]` exactly as the `[OMNI: ...]` line of the same shape, and to match on both.
