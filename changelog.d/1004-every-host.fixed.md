- **Every host prunes the database (#1004)**: pruning ran only at session start, which only Claude Code and Codex fire, so the database on other hosts grew without bound. It also ran on a thread the hook process did not wait for, so it could stop part way. The post-hook and session start now prune once a day, whichever comes first, after the reply is flushed. A test runs it three times and checks it prunes on the first call, skips the second, and prunes again a day later.
