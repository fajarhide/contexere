`contexere query timeline today` no longer says "Completed successfully (saved N% tokens)" over every command it handled. The route only says what Contexere did with the output, so a distilled `cargo build` that ended in `error[E0308]` read as a success, a claim about the user's build that nothing had checked; and the `Error` route, which means Contexere's own engine failed, read "Command failed with errors". Each line now says what Contexere did ("shortened 7516 bytes to 165; the original is kept", "passed through unchanged"), and `--json` rows carry `input_bytes`, `output_bytes` and the `handle` for `contexere retrieve`. A test feeds a failing build through the real hook and fails with the old wording put back (#1180).
