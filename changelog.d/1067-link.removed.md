- **No `omni` link, and no `omni-v…` release assets (#1067)**: Homebrew, `install.sh` and `install.ps1` installed `omni` beside `contexere` so hooks registered before the rename kept running, and every release shipped a byte-identical `omni-v…` archive. 0.9.0 installs `contexere` only and ships only `contexere-v…`. A hook or MCP entry that still calls `omni` stops working after the upgrade: `contexere doctor` has named those since 0.8.6, and `contexere init` rewrites them. An `omni` link that `install.sh` left from an earlier release is not removed and keeps running the new binary. `--version` prints `contexere` under either name. The installers read `CONTEXERE_INSTALL_DIR` and `CONTEXERE_VERSION`, and still the `OMNI_*` names, so a pinned install never falls back to `latest`. The CI upgrade test now starts from v0.8.7.
