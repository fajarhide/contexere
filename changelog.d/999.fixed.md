- **A JSON reply with a warning on stderr stays whole (#999)**: the format gate read stdout and stderr together, so one `WARNING: something deprecated` line made an 8,920 byte JSON object read as text, and it came back as 104 bytes, the warning plus `[OMNI: 606 lines omitted]`. The gate now judges stdout alone; a test sends the same 600-entry object with and without the warning and both are handed back untouched.
