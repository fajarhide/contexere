- **`contexere init` added a second post-hook beside one another program wraps (#1123)**: a PostToolUse command such as `python3 filter.py --after '/opt/homebrew/bin/omni --post-hook'` ended in `--post-hook'`, with the wrapper's quote, so init did not see it as ours, left the `omni` path in it and appended a plain `contexere --post-hook`. Every Bash, Read, Grep and WebFetch result then went through the post-hook twice, and the added copy skipped the wrapper, a secret filter in the case reported. `doctor` said nothing, so the `omni` path would have broken at 0.9.0. A hook whose last word is our flag inside a closing quote is now ours; init rewrites only the binary path inside the wrapper and adds nothing (Claude Code and Gemini CLI), and `doctor` reports a wrapped hook that still calls `omni`.
