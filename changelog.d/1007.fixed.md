- **A reindented block is no longer "identical to an earlier run" (#1007)**: the ledger keyed each line on its trimmed text, so a YAML or Python block moved from 4 to 8 spaces folded as identical to the earlier output. The key now trims only the end of the line, so CRLF and trailing spaces still match and indentation does not. Lines recorded before this release carry the old key, so an indented line seen before upgrading is not folded again until it is seen once more.
