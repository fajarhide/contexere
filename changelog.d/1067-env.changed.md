- **Only `CONTEXERE_*` settings are read (#1067)**: since 0.8.0 every `CONTEXERE_*` variable was copied onto its `OMNI_*` twin at startup and the code read the old name, so both worked. The copy is gone and the code reads `CONTEXERE_*` directly; an `OMNI_*` setting now does nothing. `contexere doctor` lists each one it finds as ignored. This includes `OMNI_AGENT_ID`, which `contexere init` wrote into the MCP entry of every host until this release and the Hermes, OpenClaw and Pi plugins set themselves: an install made before 0.9.0 is told apart from the default host only after `contexere init` runs again. `doctor` now names each host config or installed Hermes plugin that still sets it.
