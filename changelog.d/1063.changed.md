- **`~/.omni` moves to `~/.contexere` on first run (#1063)**: an install upgraded from `omni` kept its data in `~/.omni`. The first run now renames the tree to `~/.contexere`, so the database, ledger and archive move together, and on Linux and macOS leaves `~/.omni` as a symlink to it so an `omni` release and any old path still reach the data. If `~/.contexere` already exists, or the rename fails, nothing is copied and Contexere reads whichever tree exists, `~/.contexere` first. The database file keeps its `omni.db` name until a `contexere.db` exists. A test with a fake home holding `~/.omni/omni.db` and one recorded command finds it under `~/.contexere` after one `stats` run, with the same count.
