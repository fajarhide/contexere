- **`doctor` reads an MCP entry in a config with comments (#985)**: a Zed or VS Code settings file with `//` or `/* */` comments, or a trailing comma, did not parse, so a real Contexere entry in it read `not configured` and `doctor --fix` tried to write a file it then refused. The status check now reads such a file with its comments and trailing commas set aside, so the entry counts; a commented-out entry still does not, and text inside strings (a `https://` URL) is left alone. Writing to such a file is still refused, because writing it back would drop your comments (#972).
