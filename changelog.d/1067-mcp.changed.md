- **The MCP server serves `contexere_*` tools under either name (#1067)**: run as `omni --mcp`, it still advertised `omni_run`, `omni_retrieve` and the rest, so a host registered against the old name kept calling the old tools. It now serves `contexere_*` whichever name started it, and the text it hands the model names those tools. A host that still calls `omni_*` gets an unknown-tool error: run `contexere init`, which `contexere doctor` has pointed at since 0.8.6. The OpenClaw plugin's `omni_cmd` tool is `contexere_cmd`. A Cursor rule that `init` wrote before 0.9.0 names `omni_run`; `contexere doctor` now reports it as stale instead of OK, and `doctor --fix` or `contexere init --cursor` rewrites it.
