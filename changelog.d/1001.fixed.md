- **The installers verify the download (#1001)**: `install.sh` looked for `<asset>.sha256`, which no release publishes, so the check was skipped on every install, and with no hash tool it compared the expected hash with itself. `install.ps1` had no check at all. Both now read the release's `SHA256SUMS` and stop on a missing list, a missing line, a missing hash tool or a mismatch. `install.sh` was run against v0.8.4 three ways: the real asset installs, an appended byte stops with a mismatch, and an asset absent from the list is refused, both leaving nothing installed.
