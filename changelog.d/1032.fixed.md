- **`exec` and pipe no longer deliver a credential in text output (#1032)**: the distiller redacted `DB_PASSWORD=...`, then the guardrail saw an output about as long as the input and handed the raw bytes back, so the secret reached the caller on every short or plain-text payload, with or without the JSON line the report named. The text is now redacted in place before any stage runs, with the notice on stderr as for JSON (#1021). Separately, a payload holding one JSON line skipped redaction on the hook path too; that branch now hides the credential and keeps every other byte.
