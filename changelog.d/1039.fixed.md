- **A pinned provider package keeps its version (#1039)**: `pip freeze` printed `openai==2.9.0` and `anthropic==0.40.0` as `openai=[REDACTED]`, because a bare provider name matched the `OPENAI_` and `ANTHROPIC_` prefixes and `==` was read as an assignment. A key that is only a provider name now passes when its value is a version (`2.9.0`, `==1.0.0rc1`, `"0.8.3"`). A bare integer, a word, or a longer key such as `OPENAI_API_KEY` stays hidden.
