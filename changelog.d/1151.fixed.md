- **Two text-only commands were still refused after #1130 (#1151)**: `grep -c` with a pattern that itself reads `bash -e -c` and a source command was refused, because a `-c` handed the next word over to a shell found anywhere earlier in the stage, here inside the pattern. A heredoc opened inside `"$(...)"`, as in `printf '%s\n' "$(cat <<'EOF'` with `cat .env` in its body, was refused too: the opener scan skipped everything in double quotes, so the body was read as a command. The shell before a `-c` now has to be in command position itself, and the scan enters a substitution inside double quotes. Neither shape could leak, since both read nothing.
