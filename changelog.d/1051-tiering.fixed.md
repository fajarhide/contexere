- **A Python traceback keeps its location under any command (#1051)**: the `Traceback (most recent call last):` rule fired only when the command started with `python` or `pytest`, so a traceback routed to any other distiller lost the header and the `File "...", line N` frame while its `^^^` caret row and the error line survived.
