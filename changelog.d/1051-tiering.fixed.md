- **A Python traceback keeps its location from any command (#1051)**: the `Traceback (most recent call last):` rule fired only when the command started with `python` or `pytest`, so a script run behind `tar | ssh` lost the header and the `File "...", line N` frame while its `^^^` caret row and the error line survived. Both shapes now tier Critical whatever the command. Replaying the reported output through the hook now keeps the header, the frame, the source line, the caret and the error, and folds only the four `tar:` warnings.
