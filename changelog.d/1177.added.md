`contexere doctor --json` now lists each agent on its own: `id`, `name`, `tier`, whether the host is installed (`present`), whether it works (`ok`), and that agent's own warnings. Before, a home with Claude Code and Codex set up and nothing else produced one flat list of 14 warnings, 12 of them about hosts that were not installed, and nothing said which line belonged to which agent; a script or the desktop app had to parse English to find the one that mattered (Codex hooks not yet trusted). `present` is judged by the host's own directory, and VS Code by its user directory rather than the current project's `.vscode`, so the answer does not change with where `doctor` runs. The flat `warnings` list is unchanged, and a test asserts it holds the same findings as the per-agent lists (#1177).
