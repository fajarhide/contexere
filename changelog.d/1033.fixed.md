- **`OMNI_PASSTHROUGH=1` skips compression only, on every path (#1033)**: set in the environment it still delivered credentials verbatim through pipe, `exec`, the post-hook and the MCP run tool's error path, because only the user was assumed to set it. A model can type it in front of `contexere exec`, so redaction now always runs, and a credential source is withheld under passthrough too. This reverses the environment-level carve-out kept in #1028; to see raw output, run the command without Contexere. A failed command's output on hosts that report failure (Pi, Codex, `exit_code` plugins) and a successful MCP run's stderr were delivered unredacted too; both keep their bytes now, minus the credential.
