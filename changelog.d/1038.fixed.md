- **A color escape in front of a credential no longer hides it from redaction (#1038)**: `\x1b[32mDB_PASSWORD=...` was delivered on every path, because the key check read the escape as part of the key and rejected it. A line with an escape that holds no credential as written is now checked again without its escapes; if that one holds a credential it is redacted and loses its color, and a colored line without one is left as it is.
