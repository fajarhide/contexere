- **Release assets are named `contexere-v…` (#1062)**: each archive now ships as `contexere-vX.Y.Z-<target>`, with a byte-identical `omni-vX.Y.Z-<target>` copy for this release only, so an installed `install.sh` or `omni update` that asks the latest release for the old name still finds it. 0.9.0 drops the copies. The Homebrew formula, `install.sh`, `install.ps1` and `contexere update` now point at `fajarhide/contexere` and the new name. The install scripts fall back to the `omni-…` name, so pinning an older release with `OMNI_VERSION` keeps working: on v0.8.5, which only has `omni-…`, `install.sh` fell back, verified the checksum and installed.
