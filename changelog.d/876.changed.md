- **Typing `omni` at a terminal says it is now `contexere` (#876)**: the old name runs the same binary and keeps working, and until now nothing told a person they were on it. One grey line on stderr now does, and points at `contexere doctor`, which lists every hook and setting still on the old name. Stdout never changes, and the line is printed only when stderr is a terminal, so a hook or an MCP client sees nothing new; a `cmd | omni` typed at a terminal still shows it. On the built binary on Linux, `omni --version` at a pty printed the line and then `omni 0.8.5`, the same command with stderr redirected to a file left it at 0 bytes, and `contexere --version` at a pty printed only the version.
