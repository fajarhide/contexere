- **OMNI is now VENG (#876)**: the binary, MCP tools, `VENG_*` settings and docs
  carry the new name, and nothing an existing install relies on breaks. `omni`
  stays installed as a link to the same binary and serves its tools as `omni_*`,
  `OMNI_*` variables are read when the `VENG_*` twin is unset, `~/.omni` and
  `omni.db` are read in place until a `~/.veng` exists, and markers keep the
  `[OMNI` prefix. `veng migrate` moves Claude Code's hooks and MCP entry across
  and backs both files up first.
