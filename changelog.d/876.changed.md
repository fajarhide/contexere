- **Typing `omni` at a terminal says it is now `contexere` (#876)**: the old name runs the same binary and keeps working, and until now nothing told a person they were on it. One grey line on stderr now does, and points at `contexere doctor`, which lists every hook and setting still on the old name. It is printed only when stderr is a terminal, so hooks, pipes and MCP clients get the same bytes as before.
