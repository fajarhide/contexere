- **A shell launched by `docker run` or `busybox` could read a credential source unrefused (#1155)**: on main after #1154, a shell before `-c` counted only where a command starts, after wrappers, `exec`, `find -exec`, `--` or `$(`, and `docker run --rm app sh -c` and `busybox sh -c` fit none of those, so a read of a source after them was neither refused nor withheld. The guess about where a command starts is gone: a shell word outside quotes now counts wherever it sits, which fails closed and is a single pass over the arguments. `bash` inside a quoted grep pattern is still text. A bare, unquoted shell name that a command only prints (`printf '%s\n' bash -c ...`) is refused again, as it was before #1154.
