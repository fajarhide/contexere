- **A typed `OMNI_PASSTHROUGH=1` no longer delivers a secret, and the store no longer keeps one (#1003)**: `OMNI_PASSTHROUGH=1 printenv` returned a `DB_PASSWORD` that plain `printenv` hid, because the hook declined the call before redacting, and the model can type that prefix. It now skips compression only. `record_trace` kept the raw output, so a canary the model saw as `[REDACTED]` sat in `execution_traces`, and the failure hook kept the failing command and its error in the session row. Both now go through one `scrub` at the writer; tests assert the canary is absent from the stored row. Setting the variable in the environment still delivers everything, since only the user can do that.
