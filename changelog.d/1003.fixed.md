- **A typed `OMNI_PASSTHROUGH=1` no longer delivers a secret, and the store no longer keeps one (#1003)**: the prefix skips compression, but since the model can type it, credentials are now hidden in place as on a structured payload. `execution_traces` and the session row a failed command writes hold the redacted text, not the raw output. Setting the variable in the environment still delivers everything, since only the user can do that.
