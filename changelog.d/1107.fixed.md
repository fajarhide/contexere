- **A secret under a weak `*_key` name is redacted again (#1107)**: when `KEY` was the only sensitive pattern a name matched, any lowercase value under 40 characters passed as an identifier, so `KEY = "<32 hex>"`, `mailgun_key = "key-<32 hex>"` and `cache_key = "sk-ant-..."` reached the model, in bare and list form. The identifier rule now refuses a value with a provider prefix or a run of 16 or more characters mixing letters and digits. `ssh_key = "id_ed25519"` and `KEY = ("trace", "seq")` still pass; replaying the 13 distinct weak `*_key` values in a local trace corpus changed none of them.
