- **`exec` no longer delivers a credential on stderr or in a failed command's output (#1036)**: stderr was inherited, so it reached the caller without passing through Contexere, and a failed command's stdout was written as it came. Both are now captured and have their credentials hidden in place, with the notice on stderr. Nothing else changes: failed output is still never distilled, the exit code is the child's, and a person at a terminal still sees output live.
