- **A code list item naming a secret no longer hides the rest of the output (#1120)**: `"automation.webhook_secret_rotate",` followed by an array row was read as a CSV header, so every later line came back `[REDACTED]`, including the output of separate commands in the same call. A first line holding one quoted string and a trailing comma is now treated as a list item, not a header; a real header with an empty last column (`user,password,`) is still masked.
