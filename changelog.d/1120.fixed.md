- **A code list item naming a secret no longer hides the rest of the output (#1120)**: `"automation.webhook_secret_rotate",` followed by an array row was read as a CSV header, so on 0.8.5 the #1120 repro came back with 6 of its 7 lines as `[REDACTED]`, including the output of a second, independent command in the same call. A first line holding one quoted string (double or single) and a trailing comma is now a list item, and the same repro through the post-hook returns no `[REDACTED]`. A real header with an empty last column, `user,password,`, still has its password column masked.
