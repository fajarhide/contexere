- **Config writes are atomic, and the backup keeps your own file (#1006)**: every host config was written in place with `fs::write`, so an interrupted `init` could leave a truncated file, and `settings.json.bak` was overwritten on each run, so by the second `init` it held our previous edit instead of the original. Writes now go to a temporary file and are renamed over the config, the `.bak` is taken only when none exists, every host config gets one (Claude Code and Gemini had the only backups), and a symlinked config stays a link.
