- **A failed command still delivered a CSV's secret column in two shapes the #1138 fix missed (#1141)**: the MCP run tool joined a failed command's stdout and stderr before masking, and a column is found only from the first line, so `echo starting; printf 'user,password\nalice,canary\n' >&2; exit 1` reached the model with `canary`. `contexere exec` redacted a failed command's output one UTF-8 run at a time, so a single invalid byte in a row (`alic\xffe,canary`) cut the rows after it off from their header and `e,canary` came through. The MCP run now redacts each stream before joining them, and `exec` reads output that is not valid UTF-8 as one text, with the bad bytes as U+FFFD, whenever it carries a secret column.
