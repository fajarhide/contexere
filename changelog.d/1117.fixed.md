- **A redacted quoted `export` keeps the rest of its line (#1117)**: `export DATABASE_PASSWORD="v"` followed by a backtick or `;` lost everything after the closing quote, with no marker, because the redaction ran from `=` to the end of the line. It now ends with the value's shell word, so `"[REDACTED]"; tail` keeps `; tail`. A value glued to the quote (`"a"b`) is still hidden whole, and an unquoted value is still hidden to the end of the line. `` `export KEY="v"` `` wrapped in backticks was not redacted at all and now is. Seen on `gh issue list`, where a title quoting such a line came back cut.
