- **The plugins carry the Contexere name, and `contexere init` replaces the old ones (#1065)**: the OpenClaw and Hermes plugin is `contexere` (was `omni-signal-engine`), the npm packages are `@fajarhide/contexere-openclaw` and `@fajarhide/contexere-pi`, and the Claude Code plugin and skill are `contexere`. `contexere init` removes a plugin left under the old name, so it does not load twice, and carries its settings over: OpenClaw's `plugins.entries` and load path, Hermes' `plugins.enabled`, and Pi's package source. In Claude Code, install the new plugin with `/plugin install contexere@omni`, then remove `omni@omni`.
